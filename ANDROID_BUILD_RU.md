# Сборка APK Violet VPN

## Что настроено

- Web-интерфейс собирается Vite и встраивается в Android APK как локальные assets.
- Android-приложение использует `VpnService`.
- CI собирает официальный `XTLS/libXray` в AAR, подключает его к Android-модулю и собирает APK.
- APK появляется в GitHub Actions как артефакт `Violet-VPN-Android-APK`.
- Туннель не должен отображаться как подключённый, пока `libXray` не подтвердит запуск.

## Важная проверка перед релизом

Первый CI APK — диагностическая debug-сборка. Нужно проверить сборку и поведение libXray API на реальном устройстве: создание TUN, callback protect(fd), запуск/остановку Xray, IPv4/IPv6, DNS и реальное прохождение трафика. Пока эти проверки не пройдены, APK нельзя считать проверенным релизом.
